# TUNGGAL ABADI — Website GitHub Pages

Website katalog statis untuk roster beton, panel dinding, dan bata tempel.

## Isi paket
- `index.html` — struktur halaman dan konten
- `style.css` — desain responsif
- `script.js` — menu mobile dan panel pengelola demo
- `images/` — foto roster beton dan panel dinding asli dari pemilik

## Cara upload ke GitHub
1. Login ke https://github.com/
2. Buat repository baru, misalnya `tunggal-abadi`.
3. Pilih **Public** dan buat repository.
4. Klik **Add file → Upload files**.
5. Upload `index.html`, `style.css`, dan `script.js` (atau upload semua isi folder ini).
6. Klik **Commit changes**.
7. Buka **Settings → Pages**.
8. Pada **Build and deployment**, pilih **Deploy from a branch**.
9. Pilih branch `main`, folder `/ (root)`, lalu **Save**.
10. Tunggu proses selesai. Alamat situs akan tampil di bagian GitHub Pages, biasanya `https://USERNAME.github.io/tunggal-abadi/`.
